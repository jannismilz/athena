Properties

What you actually get

Most AI memory is a store you cannot open. This one is a wiki, and Wiki.js stays the source of truth for every page.

Two kinds of search

Exact terms go to the full-text index, vague questions go to the vector index, and the two lists are fused by reciprocal rank. Neither source can bury the other's hits.

Structure survives chunking

A chunk records the headings above it, so what comes back still knows it lives under Kubernetes > Network > DNS.

Visible provenance

Every page an assistant touches is stamped with which one it was and when. The name comes from the authenticated client, never from what the model says about itself.

Appends, not rewrites

Adding one fact costs a paragraph rather than a regeneration of the whole document, so the rest of the page stays exactly as you wrote it.

A dashboard with an opinion

Ships with the stack on its own port. Past the page counts it lists the searches that returned nothing, which assistant did what, and whether the last backup actually worked.

Nothing to escape from

Plain Markdown in Postgres, self-hosted, Apache-2.0. One pg_dump is a complete backup, uploads included. Walk away whenever you want.

Mechanism

How it fits together

One MCP endpoint in front of Wiki.js. Reads consult both indexes. Writes land in Wiki.js first and are re-indexed afterwards.

Interface

The tools your assistant gets

Reading and writing are both first-class, which is what lets the wiki grow through use instead of going stale.

Install

Running it yourself

Docker, a domain with TLS if you want Claude.ai to reach it, and about ten minutes.

  1. Bring the stack up

    Postgres, Wiki.js, the embedding model, and the Athena services.

  2. Set up Wiki.js

    Run the setup wizard on port 3000. This is your wiki and Athena never replaces it.

  3. Create an API token

    Administration, then API. Copy the token into .env and restart.

  4. Connect your assistant

    Add the MCP URL as a custom connector in Claude, or a bearer header in Cursor. Claude registers itself and you approve once with a password.

# clone, configure, run
git clone https://github.com/jannismilz/athena.git
cd athena
cp .env.example .env
# fill in every CHANGE_ME, generate secrets with openssl rand -hex 32
docker compose up -d

A backup container runs hourly, verifies each dump, and pushes to any rclone destination. One pg_dump is complete: Wiki.js keeps pages, users, settings and uploaded files in Postgres, and the search vectors sit beside them.

The dashboard comes up with everything else on port 8082, showing what your assistant did and which searches your wiki could not answer.
